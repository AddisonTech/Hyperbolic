Run it yourself

Everything runs on one machine: CityLearn and the dataset ship with the repository, so there is no simulator server. The rule-based and baseline controllers need no key; a model run reads its key from an environment variable and stops at the budget you set.

# Windows PowerShell, Python 3.10 to 3.12
git clone https://github.com/AddisonTech/Hyperbolic
cd Hyperbolic
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install --no-deps CityLearn==3.0.2
.\.venv\Scripts\python -m pip install -e ".[dev]"

# Watch a run live in your browser on 127.0.0.1
.\.venv\Scripts\python -m hyperbolic serve

# Or from the command line: a rule-based month,
# a model month with a key set, then compare
.\.venv\Scripts\python -m hyperbolic run --scripted
.\.venv\Scripts\python -m hyperbolic run --budget 2.00
.\.venv\Scripts\python -m hyperbolic compare

On macOS or Linux, use python in place of .\.venv\Scripts\python. Every run is saved and hyperbolic replay reproduces it with no model or simulator calls.

This is a simulator, not a real building. Every number on this page comes from CityLearn, an open source district energy simulator, scored by CityLearn's own KPIs. Nothing here is connected to a real building, BAS or customer system. A win in simulation is a reason to look closer, not proof of savings in the field.
