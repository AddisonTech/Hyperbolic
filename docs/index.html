Run on a machine that can reach api.boptest.net, with the key in an environment variable only. Then rebuild the data and commit docs/data. BOPTEST runs replace the sample one scenario at a time.

# PowerShell, from the repository folder
py -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -e .
$env:HYPERBOLIC_ANTHROPIC_KEY = "your key"
hyperbolic baseline
hyperbolic run
hyperbolic compare
git add docs/data; git commit -m "Add BOPTEST runs"; git push
This is a simulator, not a real building. Every number on this page comes from BOPTEST (or, for the sample, an offline mock of it) and is graded by BOPTEST's own KPIs. Nothing here is connected to a real building, BAS or customer system. A win in simulation is a reason to look closer, not proof of savings in the field.
